# Convenciones

- Código y comentarios en español.
- Funciones de lógica **puras**: reciben la lista y devuelven una lista nueva
  (no mutan la entrada). La persistencia vive solo en `almacen.py` y en `_main`.
- Cada feature nueva añade sus tests en `ejemplo/tests/`.
- Nombres de funciones en `snake_case` y sin acentos (`anadir`, `buscar`).
